# cowsay-java
Just type whatever you want :)

Prerequisites:
- **JDK 8+ Installed**
- **Git Installed**
---

## How to Run

1. Clone the repository:
```bash
git clone https://github.com/dallagnoldev/cowsay-java.git
```

2. Navigate to the project directory
```bash
cd cowsay-java
```

3. Run and Compile
```bash
javac Main.java && java Main
```
